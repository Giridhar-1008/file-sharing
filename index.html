Core Features

Everything you need to manage your digital files.

Designed with modern cloud standards, intuitive folder trees, and fast client-side file operations.

Role-Based Access Control

Tailored privileges for Administrator, Faculty, Student, and Guest accounts. Protected actions are verified automatically.

Drag & Drop HTML5 File API

Upload multiple files via drag-and-drop with live progress queues. Metadata persists in LocalStorage and binaries in IndexedDB.

Universal In-Browser Preview

Instant modal previews for PDF documents, images, videos, audio streams, spreadsheets/CSVs, and source/text files.

Version Control & Timeline

Track revisions per file, commit new versions with changelog notes, inspect authors and timestamps, and restore any prior draft.

Collaboration & Public Links

Share via email with Viewer, Commenter, or Editor roles, manage collaborators, and copy one-click public sharing links.

Canvas API Storage Analytics

Interactive HTML5 Canvas donut and bar charts tracking storage distribution, monthly upload volumes, and download counts.
